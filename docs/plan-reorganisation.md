# Réorganisation BeHoop / Espace Club (validée, à réaliser)

## Onglets
- BeHoop (tout le monde) : **Tribune** (fil) · **Arena** (recherche, icône loupe) · **Shoot** (publier) · **Saison** (agenda : matchs suivis ; + entraînements et Hoop Camp pour les membres) · **Vestiaire** (fan : favoris + « Rejoindre une équipe » ; joueur/parent : Hoop Camp, à valider, Équipe privée photos/vidéos, covoiturage, Playbook en lecture, membres ; coach/admin : + bouton Espace Club)
- Espace Club (coachs et admins uniquement) : **Banc** (tableau de bord) · **Effectif** (joueurs, rôles, demandes, QR, programmes Hoop Camp) · **Séances** (entraînements) · **Playbook** (tactique + exercices)
- Profil par l'avatar ; Modération pour le super admin.
- NL : Tribune, Arena, Shoot, Seizoen, Kleedkamer / Bank, Selectie, Trainingen, Playbook. EN : Courtside, Arena, Shoot, Season, Locker room / Bench, Squad, Practices, Playbook.

## Rôles et entrée
- Un seul système : la demande d'accès BeHoop (joueur / parent de… / coach), le QR code ouvre cette demande.
- Acceptation : joueur/parent → coach de l'équipe (sinon admin du club) ; coach → admin du club ; admin → super admin.
- Coach = responsable de l'équipe, admin = responsable du club, automatiquement. Accepter un joueur crée sa fiche, un parent est relié à l'enfant.
- Invitation e-mail : seulement le super admin pour nommer le premier admin d'un club.
- Joueurs et parents : plus d'accès à l'Espace Club (tout dans le Vestiaire).
